# Licences

| File | Applies to |
|---|---|
| `../LICENSE` (MIT) | this project's own code, documentation and rule files |
| `LGPL-2.1.txt` | atracdenc (`src/atracdenc/`, and the compiled program in the release downloads); `src/atracdenc/at3p_frame.patch`; pycdlib in the release downloads; libsndfile in the Linux and macOS release downloads |
| `BSD-2-Clause-libgha.txt` | libgha, inside `src/atracdenc/src/lib/libgha/` |
| `BSD-3-Clause-kissfft.txt` | KISS FFT, inside libgha (its notice and the BSD-3-Clause text it refers to) |
| `GPL-3.0.txt` | pyeboot, and the release downloads as a whole (they contain pyeboot) |
| `PSF-2.0-python.txt` | Python and its standard library, in the release downloads |
| `TclTk-tk.txt` | Tcl/Tk (the patcher's window), in the release downloads |
| `GPL-2.0-with-bootloader-exception-pyinstaller.txt` | the PyInstaller bootloader, in the release downloads |
| `BSD-3-Clause-numpy.txt` | NumPy, in the release downloads (with the notices of the parts NumPy itself includes) |
| `MIT-CMU-pillow.txt` | Pillow, in the release downloads (with the notices of the image libraries Pillow includes) |
| `BSD-3-Clause-capstone.txt` | Capstone, in the release downloads |

The NumPy, Pillow, Capstone and PyInstaller texts are the licence files shipped with those packages (NumPy 2.2.6,
Pillow 12.3.0, Capstone 5.0.9, PyInstaller 6.22.3); the Python text is the one shipped with Python 3.10; the Tcl/Tk
text is `license.terms` from the Tk source (github.com/tcltk/tk).
`../THIRD_PARTY.md` lists every third-party part with its source.
